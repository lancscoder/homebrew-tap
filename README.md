# lancscoder/tap

Homebrew casks for [lancscoder](https://github.com/lancscoder)'s apps.

```sh
brew install --cask lancscoder/tap/ration
```

| Cask | App |
|---|---|
| `ration` | [Ration](https://github.com/lancscoder/ration): Claude Code usage limits, burn rate, tokens and sessions in the macOS menu bar |
